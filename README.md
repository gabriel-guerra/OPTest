# OPTest
Test framework for IBM OpenPages

## Installation

- Download Python 
   - Recommended version: [3.12.8](https://www.python.org/downloads/windows/)
- Clone repository
- Run "script_installation.bat" to install dependencies
- Run OPTest access the GUI
